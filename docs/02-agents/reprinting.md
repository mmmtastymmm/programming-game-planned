# Reprinting Economics

- Reprint cost = original print cost (no discount) — the *sting* is XP, not extra resources.
- **Print cost is a match setting, default FREE** — a colony must never be soft-locked (no resources + no bots = no way to gather resources). Population stays bounded by printer dials and colony capacity. **The build receipt is literal (Q72)**: refunds and salvage return fractions of what was *actually spent* on the bot — a free print's chassis line is 0, while upgrades — tool grades and capacity buys, never free — always count (the module tier is deleted, Q111). "Scrapping never mints resources" holds automatically under every print-cost setting; rookie wrecks are worth ~nothing plus decryption, veteran wrecks are rich.
- Printers keep a **reprint queue** UI: destroyed bots appear with one-click requeue — a convenience counter for "my fleet lost a body," producing a fresh stock print whose color comes from the allocation (Q73). Nothing per-bot is resurrected.
